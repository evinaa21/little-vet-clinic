# Little Vet Clinic

A floating macOS widget that runs your to-do list as a tiny veterinary practice.
Tasks are patients. Each one arrives with an illustrated animal face, waits on the
board, and gets stamped `SEEN ♡` when you're done with it. The whole panel is a
printed intake sheet on a clipboard — clip bar, off-white paper, dashed rules, and
a torn-off perforated bottom edge.

Requires macOS 13 (Ventura) or later.

---

## Running it

```bash
open LittleVetClinic.xcodeproj    # then ⌘R
```

The project file is committed, so Xcode alone is enough. If you'd rather
regenerate it from `project.yml`:

```bash
brew install xcodegen
xcodegen generate
```

## Using it

| | |
|---|---|
| **Check in a patient** | Type in the field, press Return. A random animal is assigned and stays with that task for life. |
| **Mark one seen** | Click the row. Ink stamp, thud, pill flips to `SEEN ♡`, the face swaps to its happy state. |
| **Undo** | Click it again. |
| **Discharge** | Hover the row, click the ✕. |
| **Move the clipboard** | Drag the grey clip bar at the top. The position is remembered. |
| **Show / hide** | ⌥Space, or left-click the menu bar paw. |
| **Sound on/off, Quit** | Right-click the menu bar paw. |

Patients seen on an earlier day go home overnight; whoever is still waiting stays
on the board.

Everything lives in one file, and there is no network access at all:

```
~/Library/Containers/com.littlevetclinic.LittleVetClinic/Data/
  Library/Application Support/LittleVetClinic/patients.json
```

## The animal art

Nine PNGs — three animals × three moods:

| Animal | Assets |
|---|---|
| Dog | `dog_waiting.png` · `dog_seen.png` · `dog_celebrating.png` |
| Cat | `cat_waiting.png` · `cat_seen.png` · `cat_celebrating.png` |
| Bunny | `bunny_waiting.png` · `bunny_seen.png` · `bunny_celebrating.png` |

**Drop them in [`ArtDrop/`](ArtDrop/) and run `./scripts/import_faces.sh`.** Each
one is trimmed to its alpha bounds, scaled so its longest side matches every other
face, and centred on a square 256×256 sheet before being installed under
`AnimalFaces`. That step matters more than it sounds: illustrations come back
cropped to their own artwork, so without it a 709×619 sleepy bunny and a 692×677
cat land in the badge at visibly different scales.

Specs, in short: any canvas size, transparent background, face only, and **no
circle behind the face** — the pastel disc is a SwiftUI `Circle` drawn by the app,
and its colour cycles blush → sage → lavender down the rows independently of which
animal is in it. That's deliberate: nine separately generated illustrations would
never agree on a shade or a margin, and drawing the badge in code means every row
matches exactly. [`ArtDrop/README.md`](ArtDrop/README.md) has the full brief.

`celebrating` is used **only** on the closed-clinic screen, never on a row.

Until real art arrives, the app ships flat placeholder faces generated by
`scripts/make_art.swift`, so it builds and runs as-is.

### Regenerating the generated assets

```bash
swift scripts/make_art.swift                                    # placeholder faces, app icon, dmg background
python3 scripts/make_sounds.py                                    # stamp.wav and unroll.wav
```

Both are pure standard library — nothing to install.

## Shipping a .dmg

### With a paid Apple Developer account ($99/yr) — the zero-friction path

1. **Product → Archive** in Xcode.
2. **Distribute App → Direct Distribution** (Developer ID). Xcode signs, uploads
   for notarisation, and staples the ticket.
3. Package the exported app:

   ```bash
   ./scripts/make_dmg.sh /path/to/exported/LittleVetClinic.app
   ```

4. Notarise the disk image itself so the download opens on a double-click:

   ```bash
   xcrun notarytool submit dist/LittleVetClinic.dmg --keychain-profile "clinic" --wait
   xcrun stapler staple dist/LittleVetClinic.dmg
   ```

### Without one — unsigned

```bash
./scripts/make_dmg.sh
```

Builds Release with ad-hoc signing and packages it. **Tell people to right-click
the app and choose "Open" the first time**, then "Open" again in the dialog.
Double-clicking an unsigned app gets a Gatekeeper refusal with no obvious way past
it; the right-click route is the whole workaround. Worth putting that sentence
directly on the download page, not just in a README.

Either way the .dmg opens onto the paper-and-clipboard background from
`scripts/dmg/`, with the app on the left and an Applications shortcut on the
right.

## How it's put together

```
LittleVetClinic/Sources/
  App/     LittleVetClinicApp · AppDelegate · FloatingPanel · HotKeyManager
           PanelPresentation — drives the unroll on open and the retract on close
           SoundPlayer       — the stamp, and the feed motor
  Model/   Patient · PatientStore · AppSettings
  Theme/   Clinic            — palette, the two type families, metrics
  Views/   ClipboardView     — the whole sheet
           PatientRowView    — one row, and the two-beat stamp
           AnimalAvatarView  — mood crossfade, hop, breath, sleepy "z"
           ClinicClosedView  — the three-beat closing celebration
           PaperParts        — torn sheet, unroll mask, rules, clip, key cap
           RowTransitions    — arriving from the side, tearing off the bottom
           StampViews · StatusPill · TallyLine
           AppKitBridges     — window dragging, click-to-activate
```

A few things that are less obvious than they look:

- **The torn edge is the window's actual silhouette.** The panel is transparent and
  the paper is clipped to a `TornSheet` shape, so the teeth along the bottom show
  the desktop through them rather than being drawn onto a rectangle.
- **The unroll is a mask, not a height change.** The sheet keeps its full layout
  size the whole time and `UnrollMask` grows a path downward over it, so the header
  clears the clip first, each row reveals as the edge passes it, and the footer
  lands last. Animating the real height instead would have the window resizing
  sixty times a second.
- **That mask is a `Shape` with `animatableData`, not a scaled rectangle.** A mask
  driven by `scaleEffect` rasterises the sheet through a transformed layer and
  small text — the tally lines, the key cap — drops out of the composite entirely.
  Animating the path keeps the text drawing normally.
- **The sleepy "z" and the sparkles each carry two state values, not one.** Drive
  opacity off the same value as the travel and it has to start and end at zero;
  SwiftUI interpolates between those endpoints and animates invisible to
  invisible, so nothing ever appears. Position and opacity are kept apart.
- **The panel is non-activating**, so a click can tick a patient off without
  stealing focus from what you were doing. That breaks typing, so an invisible
  `ClickToActivate` shim sits over the check-in field while it's unfocused: one
  click brings the app forward *and* drops the caret in.
- **⌥Space is registered through Carbon**, which is still the only way to take a
  global shortcut without asking for Accessibility permission.
- **The check-off is two beats and the removal is one.** The stamp head drops and
  shrinks, and only on contact does the ink bloom out from under it while the head
  lifts away — that gap is the whole difference between a stamp landing and a badge
  appearing. A discharge does something unrelated on purpose: the row tips, slides
  off the bottom edge and fades. Completion is a stamp; removal is a tear, and the
  board should never leave you unsure which just happened.
